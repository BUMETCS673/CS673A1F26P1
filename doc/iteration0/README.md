# AI Movie Recommendation Chat Bot

CS673 Software Engineering · Team 1

## Overview

This project aims to help users find movies through a chat interface. A user can describe what they want to watch in natural language, such as a genre, mood, release year, or runtime, and receive a list of movie recommendations with basic information. The project is currently in the planning stage; the features below describe our proposed scope.

## Planned features

**Core features**
- Accept movie requests in natural language.
- Recommend movies based on the request.
- Identify preferences such as genre and release year and show the recognized preferences to the user.

**Additional features, if time allows**
- Show movie details such as a synopsis, poster, cast, and director.
- Refine recommendations through follow-up messages.
- Save movies to a personal watchlist.
- Provide multilingual chat and streaming-platform information.

## Proposed tools

The SPPP considers a web frontend using HTML, CSS, and JavaScript or React, with a Python or Java backend. A movie data API and an AI API may be used. The final technology choices and setup instructions will be added after the team confirms and implements them.

We plan to use GitHub branches and pull requests for collaboration. Team members will review changes before they are merged. GitHub Issues will be used to track defects during development.
